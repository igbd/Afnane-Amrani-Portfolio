## How to Restore

To restore either case study:

1. Copy the `<article>` block from the respective `.html` file.
2. Paste it back into [`index.html`](../../index.html) inside `<div class="case-studies-stream">`.
3. Uncomment or add the corresponding navigation pill in both:
   - The desktop floating pill nav (`<nav class="floating-pill-nav">`)
   - The mobile pill bar (`<nav class="case-nav-mobile-bar">`)
4. Adjust the case sequence numbers (`01`, `02`, `03`, `04`, etc.) as needed.
