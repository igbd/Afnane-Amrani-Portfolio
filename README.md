## ⚡ Tech Stack & Architecture

- **Semantic HTML5** with modern component architecture and accessibility features.
- **Vanilla CSS3** — Curated typography, refined color palette (Deep Burgundy `#4A1521`, Warm Cream `#FAF7F2`, Gold Accent `#D4AF37`), dynamic glassmorphism, responsive grid layouts, and realistic iPhone hardware mockups.
- **Vanilla JavaScript (ES6+)**:
  - Interactive iPhone phone mockups with HTML5 autoplay video loops and individual audio unmuting.
  - Interactive Before/After sliders and 360° approach hover diagram linkage.
  - Recommendation letter zoom viewer modal.
  - Active navigation ScrollSpy and mobile navigation drawer.

## 🚀 Getting Started Locally

To run the portfolio website locally:

```bash
# Clone the repository
git clone https://github.com/igbd/Afnane-Amrani-Portfolio.git

# Navigate to project directory
cd Afnane-Amrani-Portfolio

# Start a local static server
python3 -m http.server 8080
```

Open your browser and navigate to:
```
http://localhost:8080/
```
